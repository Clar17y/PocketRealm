# PvP Dossier: Opponent Pattern Analysis

**Category:** feature
**Priority:** medium
**Scope:** medium

## Description
After accumulating multiple PvP interactions (fights + scouts) against the same opponent, the arena unlocks a "Dossier" tab that surfaces behavioral patterns derived from match history: preferred attack style frequency, template category bias shifts after wins vs losses, typical ELO bracket positioning, and time-of-day activity windows. This creates a meta-game layer where experienced arena fighters must vary their strategies to remain unpredictable, and dedicated scouts gain a tangible intelligence advantage. The data already exists across PvpMatch, PvpScoutLog, and combat log JSON -- the feature just needs aggregation queries and a compact summary UI on the scout result screen.
