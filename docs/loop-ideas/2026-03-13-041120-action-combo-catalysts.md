# Action Combo Catalysts

**Category:** feature
**Priority:** medium
**Scope:** medium

## Description
Introduce a generalized combo system where specific action sequences within a combat trigger amplified "catalyst" effects. Currently there is one hard-coded combo (execute + marked_for_death = 3x damage), but the rich action/effect vocabulary (Burn, Poison, Bleed, Frozen, Curse, Armor Break, etc.) is underutilized for cross-action synergies. Define a data-driven combo registry: when a player lands action A while the target already has effect B, a catalyst bonus fires (bonus damage, effect spread, duration extension, or resource refund). For example, Frost Nova on a Bleeding target triggers "Shatter" for bonus burst damage, or Flame Sword on a Cursed target triggers "Immolate" extending the burn duration. This rewards players who thoughtfully sequence their combat template slots and creates build diversity beyond raw stat optimization, turning template editing into a puzzle of chaining setup actions into payoff combos.
