## State Issues

### 1. `sorted` array re-computed every render without memoization
**Severity:** low
**Lines:** 88-98

`[...filtered].sort(...)` creates a new sorted array on every render. With potentially many achievements, this could cause unnecessary re-renders of child components. Minor since the sort is a simple comparator.

**Suggested Fix:** Wrap in `useMemo`:
```tsx
const sorted = useMemo(() => [...filtered].sort(...), [filtered]);
```
