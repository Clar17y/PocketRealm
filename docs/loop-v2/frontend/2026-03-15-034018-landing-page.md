## Accessibility

### 1. Zone showcase carousel has no keyboard navigation
**Severity:** medium
**Lines:** 92-119

The horizontal zone showcase uses `overflow-x-auto` with `snap-x` for mouse/touch scrolling, but there's no keyboard mechanism to scroll through zones. Users relying on keyboard navigation can't access zones that overflow off-screen.

**Suggested Fix:** Add left/right arrow buttons flanking the carousel, or use `tabIndex={0}` on the scroll container with `aria-label="Zone showcase"` and instructions for arrow key scrolling.
