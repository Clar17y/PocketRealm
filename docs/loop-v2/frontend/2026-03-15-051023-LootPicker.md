## Accessibility

### 1. Close button lacks aria-label
**Severity:** low
**Lines:** 64-69

The `<X>` close button has no `aria-label`.

**Suggested Fix:** Add `aria-label="Close"`.

### 2. Custom checkboxes lack proper checkbox semantics
**Severity:** medium
**Lines:** 91-121

Items use `<button>` elements with visual checkboxes (styled divs with checkmarks). These lack `role="checkbox"` and `aria-checked`. Screen readers can't determine selection state.

**Suggested Fix:** Add `role="checkbox"` and `aria-checked={isSelected}` to each item button, plus `aria-label={item.templateName}`.
