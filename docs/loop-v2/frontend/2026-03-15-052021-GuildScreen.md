## State Issues

### 1. `loadGuild` causes full-screen loading flash on every refresh
**Severity:** medium
**Lines:** 38-50, 56-63

Like the FriendsScreen issue: `loadGuild` always sets `setLoading(true)`, which triggers the full-screen `LoadingCard` at line 56. After joining a guild or navigating between tabs that call `loadGuild`, the entire screen flashes to loading state.

**Suggested Fix:** Only show full loading on initial mount:
```tsx
const hasLoaded = useRef(false);
const loadGuild = useCallback(async () => {
  if (!hasLoaded.current) setLoading(true);
  // ...fetch...
  hasLoaded.current = true;
  setLoading(false);
}, []);
```
