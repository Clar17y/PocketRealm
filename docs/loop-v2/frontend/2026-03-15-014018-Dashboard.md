# Frontend Audit: Dashboard

**Component Audited:** `apps/web/src/components/screens/Dashboard.tsx` (349 lines)
**Date:** 2026-03-15

---

## Accessibility

### 1. Attribute "+1" buttons lack aria-labels
**Severity:** medium
**Lines:** 294-301

Six "+1" buttons for allocating attribute points have no `aria-label`. Screen readers see "plus 1" with no context about which attribute the button affects.

**Suggested Fix:**
```tsx
<button aria-label={`Add 1 point to ${meta.label}`} ...>+1</button>
```

### 2. Tooltip divs use opacity hover without keyboard focus support
**Severity:** low
**Lines:** 151-154, 171-174, 191-194

Action button tooltips ("Over-encumbered" / "Recover first") appear on `group-hover` only. Keyboard users who tab to the disabled button can't see the tooltip.

**Suggested Fix:** Add `group-focus-within:opacity-100` alongside `group-hover:opacity-100`, or use `title` attribute on the button as a simpler alternative.

---

## Component Duplication

### 1. Disabled action button + tooltip pattern repeated 3 times
**Severity:** medium
**Lines:** 136-155, 156-175, 176-195

Three action buttons (Explore, Mine, Craft) share the exact same structure: `<div className="relative group">` → `<PixelButton>` → conditional tooltip div with identical class string and same `isOverEncumbered ? ... : 'Recover first'` logic. The tooltip div is an 80-character class string duplicated verbatim.

**Suggested Fix:** Extract a `<DashboardActionButton>` component:
```tsx
function DashboardActionButton({ icon: Icon, label, screen, disabled, disabledReason, onNavigate }: {
  icon: LucideIcon; label: string; screen: string;
  disabled: boolean; disabledReason?: string; onNavigate: (s: string) => void;
}) {
  return (
    <div className="relative group">
      <PixelButton variant="primary" className="w-full" onClick={() => onNavigate(screen)} disabled={disabled}>
        <div className="flex items-center justify-center gap-2">
          <Icon size={18} />{label}
        </div>
      </PixelButton>
      {disabled && disabledReason && (
        <div className="absolute bottom-full left-1/2 -translate-x-1/2 mb-2 ...">
          {disabledReason}
        </div>
      )}
    </div>
  );
}
```
Eliminates ~40 lines of repeated JSX.
