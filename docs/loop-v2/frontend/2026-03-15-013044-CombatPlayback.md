# Frontend Audit: CombatPlayback

**Component Audited:** `apps/web/src/components/combat/CombatPlayback.tsx` (353 lines)
**Date:** 2026-03-15

---

## Accessibility

### 1. Action flash area has no aria-live region
**Severity:** low
**Lines:** 252-298

The action flash shows dynamic combat events (damage numbers, dodge, crit, etc.) that change with each revealed entry. No `aria-live` attribute means screen readers don't announce these updates. Low priority since this is a visual animation — the full log is accessible below.

**Suggested Fix:** Add `aria-live="polite"` to the flash container if screen reader support for combat playback is desired.

---

## Component Duplication

### 1. Default stamina/mana max values hardcoded
**Severity:** medium
**Lines:** 52-55

```tsx
playerMaxStamina = 100,
playerMaxMana = 50,
opponentMaxStamina = 100,
opponentMaxMana = 50,
```

These defaults are used when callers don't pass explicit max values. The same hardcoded values appear in `BossEncounterPanel` (lines 447, 454). If a player has different max values from attributes/gear, the resource bars show incorrect proportions when the caller relies on defaults.

**Suggested Fix:** Import the defaults from shared constants (if they exist), or remove the defaults and require callers to always pass explicit values. Most callers already do — making the props required would surface any that don't.

## State Issues

No issues found. The playback state machine (playing → finished-auto / finished-manual) is well-implemented:
- Timer-based reveal with proper cleanup on unmount
- Auto-skip for known mobs avoids rendering
- Backward search for latest stamina/mana values is correct and performant
- Shake animation uses refs to avoid stale state

---

## UX Issues

No issues found. The component handles its core job well — progressive log reveal, shake animations, resource bar updates, action flash text, and clean phase transitions. The 1.5s auto-advance on victory is intentional for flow (the full log is available in CombatScreen afterward).
