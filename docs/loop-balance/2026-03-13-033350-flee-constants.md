# FLEE_CONSTANTS Analysis

## Current Values

| Constant | Value | Description |
|---|---|---|
| `BASE_FLEE_CHANCE` | 0.30 (30%) | Flee chance when evasion = mob level |
| `FLEE_CHANCE_PER_LEVEL_DIFF` | 0.02 (2%) | Adjustment per (evasion - mobLevel) |
| `MIN_FLEE_CHANCE` | 0.05 (5%) | Floor against much higher mobs |
| `MAX_FLEE_CHANCE` | 0.95 (95%) | Ceiling against much lower mobs |
| `HIGH_SUCCESS_THRESHOLD` | 0.80 | Top 20% of successful rolls = clean escape |
| `HIGH_SUCCESS_HP_PERCENT` | 0.15 (15%) | HP retained on clean escape |
| `PARTIAL_SUCCESS_HP` | 1 | HP on wounded escape (always 1) |
| `GOLD_LOSS_MINOR` | 0.05 (5%) | Gold lost on clean escape |
| `GOLD_LOSS_MODERATE` | 0.15 (15%) | Gold lost on wounded escape |
| `GOLD_LOSS_SEVERE` | 0.30 (30%) | Gold lost on knockout |

## Analysis

### Core Formula

```
fleeChance = clamp(0.30 + (evasion - mobLevel) * 0.02, 0.05, 0.95)
```

This is a **linear** scaling function. Each evasion level above the mob adds 2% flee chance; each level below subtracts 2%.

### Breakpoints

Key level differences and their flee chances:

| evasion - mobLevel | Flee Chance | Notes |
|---|---|---|
| -13 or lower | 5% (floor) | Floor reached at delta = -12.5, so -13 |
| -10 | 10% | |
| -5 | 20% | |
| 0 | 30% | Equal levels |
| +5 | 40% | |
| +10 | 50% | Coin flip |
| +15 | 60% | |
| +20 | 70% | |
| +25 | 80% | |
| +30 | 90% | |
| +33 or higher | 95% (ceiling) | Ceiling reached at delta = 32.5, so +33 |

**The floor is hit at -13 levels.** Below that, no further punishment. The ceiling is hit at +33 levels. The full dynamic range spans 46 levels of difference.

### Outcome Probability Breakdown

Given a flee chance `p`, the three outcomes have these probabilities:

- **Knockout**: `1 - p` (failed flee)
- **Wounded Escape**: `p * 0.80` (bottom 80% of success range)
- **Clean Escape**: `p * 0.20` (top 20% of success range)

At key level deltas:

| Delta | Flee % | Knockout % | Wounded % | Clean % |
|---|---|---|---|---|
| -13 | 5% | 95.0% | 4.0% | 1.0% |
| -5 | 20% | 80.0% | 16.0% | 4.0% |
| 0 | 30% | 70.0% | 24.0% | 6.0% |
| +5 | 40% | 60.0% | 32.0% | 8.0% |
| +10 | 50% | 50.0% | 40.0% | 10.0% |
| +20 | 70% | 30.0% | 56.0% | 14.0% |
| +33 | 95% | 5.0% | 76.0% | 19.0% |

### Expected Gold Loss Per Defeat

Expected gold loss as a fraction of current gold:

```
E[gold_loss%] = P(knockout)*0.30 + P(wounded)*0.15 + P(clean)*0.05
             = (1-p)*0.30 + p*0.80*0.15 + p*0.20*0.05
             = 0.30 - 0.30p + 0.12p + 0.01p
             = 0.30 - 0.17p
```

| Delta | p | E[gold_loss%] |
|---|---|---|
| -13 | 0.05 | 29.15% |
| 0 | 0.30 | 24.90% |
| +10 | 0.50 | 21.50% |
| +20 | 0.70 | 18.10% |
| +33 | 0.95 | 13.85% |

Even at maximum flee chance (+33 levels), expected gold loss per defeat is still ~14%. The range only spans 15 percentage points (29% to 14%), so **evasion has modest impact on gold preservation**.

### Knockout Cost Analysis (Cross-System Interaction)

Knockout triggers three penalties simultaneously:
1. **Gold loss**: 30% of current gold
2. **Recovery cost**: `maxHp * 1` turns (from `HP_CONSTANTS.RECOVERY_TURNS_PER_MAX_HP = 1`)
3. **Respawn to home town**: Must travel back (100+ turns per zone hop via `ZONE_CONSTANTS.BASE_TRAVEL_COST = 100`)
4. **Recovery exit HP**: Only 25% of max HP on exit (from `HP_CONSTANTS.RECOVERY_EXIT_HP_PERCENT = 0.25`)

**Recovery cost scaling with vitality:**

```
maxHp = 100 + vitality * 5 + equipmentHealthBonus
```

| Vitality | MaxHP (no gear) | Recovery turns | Recovery time |
|---|---|---|---|
| 1 | 105 | 105 | 1m 45s |
| 10 | 150 | 150 | 2m 30s |
| 25 | 225 | 225 | 3m 45s |
| 50 | 350 | 350 | 5m 50s |
| 75 | 475 | 475 | 7m 55s |
| 100 | 600 | 600 | 10m 0s |

With equipment health bonuses, maxHP can push higher. A well-geared level 100 player might have 800+ maxHP, meaning 800+ turns (13+ minutes) of recovery, plus 25%+ maxHP exit means they come back at only 200 HP.

### Where Flee Is Triggered

Flee mechanics activate in **four** contexts:
1. **Zone combat defeat** (combat/start route)
2. **Encounter site defeat** (combat/start handleEncounterSiteRoomCombat)
3. **Exploration ambush defeat** (exploration/start route)
4. **PvP defeat** (pvpService) -- uses mob level = opponent's character level
5. **Boss raid wipe** (bossEncounterService) -- all participants get flee rolled

Importantly, **players do not actively choose to flee**. The system automatically rolls flee on every combat defeat. The name "flee" is slightly misleading -- it's really a "defeat severity roll."

### Evasion as a Defensive Investment

Evasion serves double duty:
- **In combat**: Contributes to dodge chance (via `CHARACTER_CONSTANTS`, evasion affects speed/dodge)
- **On defeat**: Determines flee outcome severity

At equal levels, the 70% knockout rate is extremely punishing. To reach a 50/50 knockout chance, a player needs evasion 10 levels above the mob. This means **players fighting at-level content face knockout ~70% of the time on defeat**.

### The "Wounded Escape" Dead Zone

Wounded escape sets HP to exactly 1. This means:
- The player is alive but essentially one hit from death
- They cannot meaningfully fight anything without resting first
- Rest healing: `BASE_REST_HEAL + REST_HEAL_PER_VITALITY * vitality = 2 + 0.2 * vitality` HP/turn
- At vitality 25: 7 HP/turn. From 1 HP to 225 HP max = 32 turns (32 seconds)
- At vitality 50: 12 HP/turn. From 1 HP to 350 HP max = ~29 turns

Wounded escape is functionally similar to knockout in terms of "you must stop and heal" -- the main savings are avoiding the recovery state turn cost and the town respawn.

### Clean Escape Analysis

Clean escape preserves 15% HP. At maxHP 350 (vitality 50), that's 52 HP. Still dangerously low for most content, requiring rest before re-engaging. The clean escape is noticeably better than wounded (52 HP vs 1 HP) but the player is still in a "must heal" state.

Given clean escape is only 20% of successful flees, and a successful flee at equal levels is only 30%, **clean escape occurs only 6% of the time for at-level content**.

## Issues Found

### 1. Knockout Rate Is Extremely High at Level Parity

At evasion = mobLevel, knockout probability is 70%. For players fighting at-level content (the intended progression), 7 out of 10 defeats result in:
- 30% gold loss
- maxHP turns of recovery downtime
- Respawn to town + travel cost back

This creates an **extremely punishing feedback loop**: defeat is already bad (lost turns, no rewards), and the 70% knockout compounds it severely. Players might avoid challenging content entirely.

### 2. Evasion Investment Has Poor ROI for Flee

Each evasion level above mob level reduces knockout rate by only 2 percentage points. To go from 70% knockout to 50%, you need +10 evasion levels. But evasion levels also help dodge in combat, so the flee benefit is ancillary. The problem: **players who invest in evasion for combat dodge still face brutal knockout rates unless they massively out-level content**.

### 3. Gold Loss Has No Floor

Gold loss is a flat percentage with no minimum or maximum. A player with 100,000 gold loses 30,000 on knockout. A player with 10 gold loses 3. This creates a **perverse incentive to spend gold immediately** rather than save it, distorting the economy. Players will dump gold into any available sink before engaging in risky combat.

### 4. Wounded Escape Is Barely Better Than Knockout

The wounded escape outcome (80% of successful flees) leaves the player at 1 HP. Compared to knockout (0 HP + recovery):
- Saves the recovery turn cost
- Avoids town respawn
- Still loses 15% gold (vs 30%)

But at 1 HP, the player cannot do anything except rest. The practical difference between "1 HP in the field" and "knocked out" is primarily the recovery cost + travel cost. For a level 50 player with 350 maxHP, that's ~350 turns recovery + 100-200 turns travel = 450-550 turns. At 1 turn/second, that's 7-9 minutes of waiting. This makes wounded escape feel meaningful, but the HP=1 outcome still feels very punishing for what is nominally a "successful" flee.

### 5. Boss Raid Wipe Uses Individual Flee Rolls

When a boss raid wipes (all players dead), each participant gets an individual flee roll using their evasion vs the boss's level. Boss mobs are typically high-level. If a boss is level 80 and players average evasion 30, the level delta is -50, which hits the 5% floor. This means **95% knockout rate on boss wipes**, which is probably intentional but worth noting.

### 6. No Interaction With "How Close the Fight Was"

Whether a player lost at round 1 or survived 99 rounds and barely lost, the flee mechanics are identical. A near-victory gets the same brutal knockout rate as getting instantly destroyed. This feels unintuitive -- a player who nearly won should have better escape odds.

## Recommendations

### R1: Increase BASE_FLEE_CHANCE to 0.40

Reduces knockout rate at level parity from 70% to 60%. This makes defeats less punishing without removing the sting entirely. Players fighting at-level still face significant risk but not overwhelming punishment.

```
BASE_FLEE_CHANCE: 0.30 -> 0.40
```

### R2: Increase FLEE_CHANCE_PER_LEVEL_DIFF to 0.03

Makes evasion investment more impactful. Currently it takes +10 levels for a coin-flip knockout rate. At 3% per level, it would take ~7 levels, making evasion skill points feel more rewarding.

```
FLEE_CHANCE_PER_LEVEL_DIFF: 0.02 -> 0.03
```

Combined with R1: equal-level knockout drops from 70% to 60%; +7 evasion gives 81% flee chance (only 19% knockout), which properly rewards investment.

### R3: Raise PARTIAL_SUCCESS_HP to scale with maxHP

Instead of a flat 1 HP, use 5% of maxHP (minimum 1). This gives wounded-escape players a tiny buffer so they don't feel like a stiff breeze kills them.

```
PARTIAL_SUCCESS_HP: 1 -> formula: max(1, floor(maxHp * 0.05))
```

This requires a code change in `fleeMechanics.ts` to accept maxHp and use a percentage. At 350 maxHP, wounded escape would leave 17 HP instead of 1. Still desperate, but not literally one hit.

### R4: Consider a Gold Loss Floor

Add a minimum gold amount that cannot be lost (e.g., first 100 gold is protected). This prevents early-game players from feeling absolutely gutted while still punishing wealthy players proportionally.

### R5: (Future) Consider Combat Performance Factor

A "performance factor" based on rounds survived or damage dealt could modify flee chance upward. For example: if the player survived more than 50% of max combat rounds, add +10% to flee chance. This is a more complex change but would address issue #6.

## Risk Level

**medium** -- The 70% knockout rate at level parity creates a punitive experience that may drive players away from challenging content. The gold loss mechanics create economic distortions. However, the system is internally consistent and all penalties scale predictably. The main risk is player frustration rather than exploitable degenerate strategies. The strongest recommendation (R1 + R2) involves simple constant tweaks with no code changes required.
